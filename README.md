# THE MAKING OF NATIONS — Bilingual Digital Book

A responsive, static e-book website about global factors behind national progress.

## Features
- Indonesian / English language toggle
- 9 chapters with navigation
- Reading progress indicator
- Adjustable font size
- Light / dark reading mode
- Responsive layout for desktop, tablet and mobile
- Keyboard navigation (left/right arrows)
- No backend or build tools required

## Run locally
Open `index.html` in a modern browser. An internet connection is required for the optional Google Fonts and the sample Unsplash cover image.

## Publish with GitHub Pages
1. Create a new repository on GitHub, for example `nation-ebook`.
2. Upload `index.html`, `style.css`, `book.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site will be available at:
   `https://YOUR-USERNAME.github.io/nation-ebook/`

## Customisation
- Edit chapter content and translations in `book.js`.
- Change colors, typography and layout in `style.css`.
- Update the title and metadata in `index.html`.

## Editorial note
This is an educational overview, not a statistical ranking of countries. Country examples are introductory and intentionally qualitative. Add up-to-date primary sources, citations and data visualisations before using it as a formal research publication.
